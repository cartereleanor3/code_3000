The main intended user of the code/data in my repo is myself to complete coursework for CSE 3000. Another intended user would be my professor as a viewer to grade assignments submitted through gradescope. The repository is public, so technically anyone could view it, however, I decided not to change it to private in case it interfered with gradescope. 
The security risks of my repo is low because it doesn't contain any sensitive/confidential data. The main "security" risk would be if another student in the class viewed the assignments in my repo to copy and submit as their own.
I changed the CODEOWNERS file to be * @cartereleanor3 to define myself as the owner/manager of the files. I also implemented a ruleset named "Protect branch" which I modified from the sample provided on HuskyCT. The smaller tweaks I made were that I removed "id" because it is in a separate repo than the repo I forked from, renamed it, removed "source_type" as Github should automatically identify it, and removed "source" so my ruleset would be independent from the original repo. I kept "deletion" so that I don't accidentally delete my main branch, and also kept "non_fast_forward" so that I couldn't accidentally overwrite branch commit history. The main change I made was that I removed the "pull request" and codeowner rules. I did this because I am the only contributor to my fork nad I push directly to my main branch so there would be no need for my own approval or have the extra steps of making a new branch, pushing, pulling, then merging.
